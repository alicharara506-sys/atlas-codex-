# Phase 2 agentic research engine

The Phase 2 workflow is active after the provisioned PostgreSQL/Redis gate passed.
It provides seven deterministic specialist desks, bull/bear debate, weighted
arbitration, a mandatory fail-closed Risk Guard, idempotent audit persistence,
and bounded risk-parity portfolio proposals.

The engine is research-only. `execution_plan` is always empty and both paper and
live execution remain disabled by `config/policy.default.json`.
